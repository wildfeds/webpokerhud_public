## Sideload (zip)

Sideloading is fully supported and always will be — it's the documented
fallback if the Web Store listing is ever delayed or removed.

1. Download the latest release zip and unpack it to a folder you'll keep
   (Chrome loads the extension from this folder on every start).
2. Open `chrome://extensions` in Chrome.
3. Turn on **Developer mode** (toggle, top right).
4. Click **Load unpacked** and select the unpacked folder.
5. Pin the extension: puzzle-piece icon in the toolbar → pin.

Chrome shows a "developer mode extensions" notice on startup for sideloaded
extensions; this is normal.

## Updating a sideloaded install

Replace the folder contents with the new release and click the reload icon on
the extension's card in `chrome://extensions`. Your hand data is stored in the
browser profile, not the extension folder — updates never touch it.

## Requirements

- Chrome or a Chromium-based browser (Edge, Brave) with Manifest V3 support.
- No account needed. The free tier works entirely offline from our servers.
